Release log

What has shipped.

Newest first, versioned rather than dated. Fine-grained release notes for the Community Edition live with the source at github.com/SIM-DAD/tass.

0.5Statistics, charts, projectsCurrent beta

The full analysis cycle in one place, with the receipts to publish it.

  • Inferential statistics suite with assumption checks, effect sizes, corrections, post-hoc tests, and APA output, benchmarked against R golden files with a public audit report.
  • Eight deterministic publication SVG chart types with colorblind-safe palettes and embedded data tables.
  • Reproducible .tassproj archives: save a run, rerun it later, byte-compare every artifact.
  • Validation workspace: sampled human review, precision summaries, and coder-agreement reliability (Cohen's kappa, Krippendorff's alpha).
  • Desktop workbench (GUI Edition) in alpha, shipping to beta participants.
  • Public dictionary registry with sha256-pinned installs by name.
0.1 to 0.4Foundations

The clean-room engine, built in the open from requirements up.

  • Deterministic scoring engine: percent, hits, weighted, and mean metrics; group summaries; time-windowed trajectories; phrase and wildcard terms.
  • Ten bundled open dictionaries, every one verified for any use, with citations carried in every manifest.
  • TASS VADER-rules sentiment: a clean-room implementation of the published VADER heuristics, honestly labeled.
  • CLI, MCP server, and minimal local web GUI generated from one spec table so the surfaces cannot drift.
  • Provenance manifests beside every scored output: versions, input hashes, licenses, citations.
  • Importers for transcripts, chat logs, spreadsheets, LIWC-format .dic files you have licensed, and SocialSent TSVs.
