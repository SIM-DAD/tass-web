0.6.1Private beta

The first signed TASS Workbench, and the first whose license keys activate.

  • Corpus scoring against bundled lexicons (VADER with negation and booster rules, politeness strategies, Empath, SocialSent) or your own dictionary imported from a spreadsheet.
  • Intercoder reliability with Cohen’s kappa and Krippendorff’s alpha, benchmarked against R’s irr package, each with an APA-formatted sentence.
  • Deterministic corpus preparation: trim, drop blanks, minimum token count, column filters and deduplication, applied in a fixed order so the same input always gives the same output.
  • Ranked exemplars and keyword-in-context, so any number traces back to the text that produced it.
  • Projects that re-run byte-identically, with tamper detection if results were edited after the fact.
  • Inferential statistics validated against R, charts carrying their own data tables, and export to Excel or APA.
  • XLSX import, added in this release.
