Get TASS.

Two editions, one engine. The Community Edition is available today; GUI Edition beta installers ship through the beta program.

Community Edition (free, Apache-2.0)

The engine, CLI, MCP server, minimal local web GUI, and reproducible-project container. Available now from the source repository. The engine and CLI have zero runtime dependencies; Node 18 or newer is the only requirement. Runs on Windows, macOS, and Linux.

Get it from github.com/SIM-DAD/tass

Or install it in one command with npm: npm install -g @simdad/tass-cli, then tass help. The @simdad/tass-cli package carries the engine and every Community capability.

GUI Edition (desktop workbench, beta)

The no-code desktop workbench is in closed beta. Beta installers are distributed directly to beta participants; the program is free for its duration and open to researchers currently affiliated with a university or an established research institution.

At public launch, signed release installers and their SHA-256 checksums will be published at github.com/SIM-DAD/tass-releases.

What you can verify before installing anything

The methods reference documents what TASS measures and how; the benchmark report lists every statistical method with its citation and its validation against R; the user guide is the full in-product help. All three are public regardless of which edition you run.

Trial

At launch, the GUI Edition installs with a 30-day full-featured trial, capped at 10,000 rows per analysis. No credit card, no key.
